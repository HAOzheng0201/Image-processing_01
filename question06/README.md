# 问题 6：灰度图像的高斯滤波（15 分）

本题把第 3、4、5 题连接起来，对四张图片进行高斯滤波，并完成两个比较：自己实现的结果与 Python 库函数是否一致，两种边界填充在图像边缘有什么差别。

## 1. 题目要求与本程序的安排

| 要求 | 本程序的做法 |
|---|---|
| 处理四张灰度图 | cameraman、einstein 直接读取；mandril_color、runner 先按第 3 题 NTSC 公式转灰度 |
| 使用 σ=1、2、3、5 | 四张图各运行四次，共 16 个滤波结果 |
| 主实验任选填充方式 | 统一使用 `replicate`，即边界像素复制 |
| σ=1 时与库函数比较 | 四张图分别与 `scipy.ndimage.gaussian_filter` 比较，打印误差并保存差值图 |
| 任选两张图比较填充方式 | 选择 cameraman、runner，固定 σ=5 和 31×31 核，比较 `zero` 与 `replicate` |

题目中灰度图来源的交叉引用略有歧义，本程序按题目括号中明确列出的四张图执行。第 4 题函数的默认填充仍是 `zero`，本题显式传入 `replicate`，不修改前面函数的定义。

## 2. 先把数据流程连起来

```text
cameraman、einstein ──读取为浮点灰度数组─────────┐
                                               ├─ f
mandril_color、runner ──读取 RGB ── rgb1gray ────┘

sigma ── gaussKernel ── w

f、w、填充方式 ── twodConv ── g
```

核心计算可以写成三行：

```python
f = rgb1gray(rgb, "NTSC")       # 仅彩色图需要这一步
w = gaussKernel(sig)            # 生成归一化高斯核
g = twodConv(f, w, "replicate")  # 用这个核对灰度图做卷积
```

输入 f、输出 g 均为二维数组，空间尺寸不变。高斯滤波不是缩小图片，也不是把图像转换成另一种颜色模式，而是根据周围像素重新计算每个位置的灰度值。

代码从前面各题的 `main.py` 导入三个函数，不复制它们的实现。那些文件末尾有 `if __name__ == "__main__":`，所以导入只获得函数，不会自动运行前几题的实验。

直接执行 `python question06/main.py` 时，Python 首先搜索脚本所在目录。代码把作业根目录加入 `sys.path`，让它能找到旁边的 `question03`、`question04`、`question05`。这是本地文件导入，不是重新安装软件包，也不需要先运行前几题。

### 为什么不读取第 3 题已经保存的灰度 PNG？

例如一个 RGB 像素为 `[100,150,200]`，NTSC 结果是：

$$
0.2989\times100+0.5870\times150+0.1140\times200=140.74.
$$

保存成 8 位 PNG 时会取整为 141。第 6 题直接重新调用灰度转换函数，保留 140.74，让后续比较基于同一份未取整输入。两个实现若一个使用 140.74、另一个使用 141，就不是只在比较滤波算法。

灰度原图也转换为 `float64`。数值 100 变成 100.0，尺度仍是 0～255，不是除以 255。

## 3. 高斯滤波怎样改变一个像素？

### 3.1 邻居共同决定新值

用第 5 题手算的 σ=1、3×3 高斯核作为简化例子：

$$
w\approx\begin{bmatrix}
0.075114&0.123841&0.075114\\
0.123841&0.204180&0.123841\\
0.075114&0.123841&0.075114
\end{bmatrix}.
$$

本题正式的 σ=1 实验用的是 7×7 核，这里使用 3×3 只是为了便于手算。

若窗口中间为 200，周围八个像素都是 100，可以先把窗口看成全为 100，再加上中心多出来的 100：

$$
g=100\sum_{i,j}w[i,j]+100w[1,1]
\approx100+20.418=120.418.
$$

中心的突起被减弱。如果它来自噪声，平滑可能有帮助；如果它是一个细小的真实亮点，平滑也可能把细节削弱。高斯核只按距离加权，不会识别哪个变化是噪声、哪个变化是物体。

### 3.2 为什么明暗边界会模糊？

考虑一条竖直边界：左边像素全为 0，右边全为 100，各行相同。用对应的三点一维权重：

$$
p\approx[0.274069,\ 0.451863,\ 0.274069]
$$

计算横向变化即可。最后一个黑像素的窗口为 `[0,0,100]`，输出约 27.4069；第一个白像素的窗口为 `[0,100,100]`，输出约 72.5931：

```text
原来： ... 0   0    0       100      100  100 ...
之后： ... 0   0   27.4069  72.5931  100  100 ...
```

突然跳变变成过渡带。较宽的高斯核会把这种混合扩展到更远的位置，所以模糊更明显。这是图像内部的物体边缘，与画面最外圈的边界填充要区分开。

## 4. 四个 σ 应该怎样比较？

沿用第 5 题的尺寸规则：

$$
r=\lceil3\sigma\rceil,\qquad m=2r+1.
$$

| σ | 半径 r | 核尺寸 | 每个输出使用的窗口位置数 |
|---:|---:|---|---:|
| 1 | 3 | 7×7 | 49 |
| 2 | 6 | 13×13 | 169 |
| 3 | 9 | 19×19 | 361 |
| 5 | 15 | 31×31 | 961 |

窗口内不是每个位置都同样重要，越远权重越小。σ 增大后，权重分布变宽，核尺寸也随之增加，以避免把宽高斯截在很小的窗口里。

### 四次滤波都从原始灰度图开始

正确比较的是：

```python
g1 = twodConv(f, gaussKernel(1), "replicate")
g2 = twodConv(f, gaussKernel(2), "replicate")
```

不能先算 g1，再用 σ=2 的核处理 g1，拿它当作“原图 σ=2 的结果”。连续平滑会累积影响。在理想连续、无限范围高斯模型中，连续两次滤波的方差相加：

$$
\sigma_{\mathrm{effective}}=\sqrt{\sigma_1^2+\sigma_2^2}.
$$

先用 σ=1 再用 σ=2，相当于约 σ=√5≈2.236，而不是 2。有限采样、核截断和图像边界会使这个连续关系不再严格成立，但它足以说明重复模糊和独立比较不同。

### 观察什么，而不只写“变模糊了”

- cameraman：看人物、相机和背景建筑的边界，比较细小结构是否仍可辨认。
- einstein：看头发、胡须和面部细节，区分大轮廓与细纹理的变化。
- mandril_color 的灰度图：看毛发纹理和面部边界。
- runner 的灰度图：看运动员轮廓和密集的背景观众。

这些位置便于把“变模糊”落实到具体结构上。比较时始终使用同一幅输入的四个结果，例如在 [einstein 对比图](results/einstein_sigma_comparison.png) 中观察头发和胡须的细纹理，再看脸部大轮廓。细节平滑和轮廓保留是不同层次的现象。本题没有加入人工噪声，也没有无噪声真值图，不能直接根据图像更平滑就断言去噪质量更好。

## 5. 与 SciPy 比较，怎样才公平？

自己实现与库函数接近，是判断计算是否正确的一种证据。但必须先确保两边做的是同一件事。

| 条件 | 自己的实现 | SciPy 参考实现 |
|---|---|---|
| 输入 | 同一个二维浮点 f | 同一个 f |
| σ | 1 | `sigma=1` |
| 核尺寸 | 7×7 | `radius=3`，每方向长度为 7 |
| 填充 | `replicate` | `mode="nearest"` |
| 运算 | 高斯平滑 | `order=0`，不计算导数 |
| 输出类型 | `float64` | 显式 `output=np.float64` |

对应调用为：

```python
reference = gaussian_filter(
    f, sigma=1, order=0, radius=3,
    mode="nearest", output=np.float64
)
```

SciPy 的默认边界方式是 `reflect`，不是本题的边界复制。未显式指定 radius 时，其默认截断参数通常对应约 ±4σ；σ=1 时默认核通常是 9×9，而本实验是 7×7。直接调用 `gaussian_filter(f, 1)` 并不代表已经匹配全部条件。

### 为什么库函数算得不一样快，却应该得到几乎一样的数？

二维高斯可以分解成两个一维高斯的乘积：

$$
e^{-(x^2+y^2)/(2\sigma^2)}=
e^{-x^2/(2\sigma^2)}e^{-y^2/(2\sigma^2)}.
$$

在相同方形网格上离散归一化后，也有 `w[i,j]=p[i]p[j]`。因此可以先沿一个方向滤波，再沿另一个方向滤波，得到同样的二维加权和。SciPy 使用一维滤波序列，我们的 `twodConv` 直接遍历二维核。

以 31×31 核粗略比较，每像素二维直接法涉及 961 个核位置；两个一维方向各 31 个，总共约 62 个位置。这解释了可分离计算的效率优势，但本题没有计时实验，不给出实际速度倍数。

浮点加法会舍入，改变累加顺序可能产生微小差异，所以无需强求每一位完全一样。另一方面，高斯核对翻转对称，**与库函数的高斯结果吻合，仍不能单独证明第 4 题对非对称核的翻转正确**，这也是之前安排非对称手算例子的原因。

## 6. 差值图和误差数字怎样读？

程序使用未取整的浮点结果计算：

$$
D[r,c]=\left|g_{\mathrm{ours}}[r,c]-g_{\mathrm{SciPy}}[r,c]\right|,
$$

$$
\mathrm{MAE}=\frac{1}{HW}\sum_{r,c}D[r,c],
\qquad E_{\max}=\max_{r,c}D[r,c].
$$

MAE 表示每个像素平均相差多少灰度级；最大绝对差用来发现是否有少数位置误差较大。本实验额外用 `np.allclose(..., rtol=0, atol=1e-10)` 判断每个位置的绝对差是否不超过 10⁻¹⁰。这个阈值是实验约定，不是老师指定的评分门槛。

例如，一个像素的两个结果分别为 100.25 和 100.25000000000003，差异大约为 3×10⁻¹⁴，属于很小的数值差异，不是肉眼可见的灰度变化。

### 差值图很亮，是否意味着错得很大？

不一定。为了看到微小差异的分布，程序把每张差值图的最大差映射到色标最亮处。即使最大差只有 10⁻¹³，也可能出现很鲜明的颜色。因此必须同时看色标、标题中的最大差和 MAE，不能仅凭颜色亮暗判断误差大小。不同图片的差值色标可能不同，也不能直接跨图比较颜色。

差值图使用浮点热力图和色标保存，不先转为 `uint8`。例如 100.2 和 100.4 保存成最近整数后都变成 100，再比较 PNG 会得到差异 0，掩盖原本的 0.2。

若出现明显误差，可以按这个顺序排查：是否用了相同输入、是否有提前取整或归一化、核尺寸是否一致、边界方式是否相同，最后再检查卷积实现。若差异只围着图像外圈出现，优先检查填充；若内部也普遍不同，进一步检查核和数值尺度。

## 7. 两种边界填充为什么会不同？

本程序选 cameraman 和 runner，固定 σ=5、31×31 核，只改变 `zero` 与 `replicate`。固定其他条件后，观察到的差异才能归因于填充方式。

### 7.1 给画面外的像素“补什么”

想象相机拍到的是一面灰度为 100 的墙。处理左边缘时，卷积窗口有一部分伸出照片：补零假设照片外是黑色 0；复制则把最左边的墙继续延伸为 100。

用简化的一维权重 `[0.25,0.5,0.25]` 计算第一个像素：

```text
补零窗口： [0,   100, 100] → 0.25×0   + 0.5×100 + 0.25×100 = 75
复制窗口： [100, 100, 100] → 0.25×100 + 0.5×100 + 0.25×100 = 100
```

这里的三点权重仅用于说明边界机制，不是本题 σ=5 的实际核。两种结果不同，并不是卷积核变了，而是窗口所看到的图外数据不同。

### 7.2 角点为什么更明显？

用上面的一维权重生成二维外积核：

$$
w=\begin{bmatrix}
0.0625&0.125&0.0625\\
0.125&0.25&0.125\\
0.0625&0.125&0.0625
\end{bmatrix}.
$$

对全为 100 的图，左上角补零后只有窗口右下 2×2 属于原图，其权重和为 `0.25+0.125+0.125+0.0625=0.5625`，输出为 56.25。边缘中间只有一个方向越界，而角点两个方向都越界，丢失的加权份额更多。复制方式在此常数图例子中仍输出 100。

“核归一化”只保证整个窗口权重和为 1，不保证窗口内的原图像素权重和为 1。补零不会因为越界而重新分配核权重。

### 7.3 差异应该出现在哪些位置？

31×31 核半径为 15。只有距图像外边界不足 15 像素的位置，才可能使用图外填充值。内部位置的两个输入窗口完全相同，所以两种填充的结果应相同。

数组中的内部区域为：

```python
g[15:-15, 15:-15]
```

`-15` 表示从结尾向前数 15 个位置，切片不包含右端点。对 256×256 的 cameraman，内部行列索引都是 15～240，即形状 226×226；其余四周为可能受影响的边界带。

程序打印边界带的平均绝对差和内部的最大绝对差。使用边界带统计，是为了避免全图大面积相同的内部像素把平均差异稀释。两种填充都调用同一个卷积函数，因此内部理论结果一致；具体数值由运行输出核对。

对于非负输入和非负高斯权重，复制填入的是非负边界值，补零填入的是 0，所以同一位置复制结果在数学上不会低于补零结果。这个结论依赖非负条件，不能随意推广到有负系数的锐化核或差分核。

## 9. 运行后怎样整理自己的结论？

先核对三个任务是否齐全，再结合图像写观察：

1. **不同 σ：**选择具体区域，描述细节、纹理或轮廓怎样变化，解释与权重范围的关系。不要只写“σ 越大越好”。
2. **库函数比较：**记录实际 MAE、最大绝对差和比较参数。误差很小时说明在当前条件下数值接近，不夸大成所有输入均已证明正确。
3. **边界比较：**查看左上角放大图与整幅差值图，记录边界带误差和内部最大差，解释两种图外延伸假设。

如果能解释“为什么库函数默认调用不一定公平”“为什么鲜艳差值图也可能只有浮点误差”“为什么归一化核仍会产生补零暗边”，就抓住了本题比单纯生成模糊图片更重要的部分。
